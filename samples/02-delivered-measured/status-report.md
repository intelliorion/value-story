# Drawing Register Reconciliation — Status Report
Period: 2026-08
Prepared by: Design Assurance Lead

In service across three delivery teams since 2026-04-14. Q2 is the first full
quarter of operation; Q3 is now also complete.

Measured against the reconciliation export from the workflow tool:

- Median hours per register fell from 6.8 to 1.9.
- Superseded drawings issued to site fell from 19 in Q1 to 3 in Q3.
- Three delivery teams now run the check; none did before April.

Not measured:

- We have not costed the hours saved. Finance has not agreed an internal rate
  for design assurance time, so no currency figure is claimed.
- Rework avoided downstream is not tracked. We believe it is material and we
  cannot evidence it.

New capability: the check compares the issued register against the document
management system automatically. Before April this comparison was only done
when someone suspected a problem, which meant it was never done routinely.
