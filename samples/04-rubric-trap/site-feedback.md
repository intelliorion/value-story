# Site feedback summary — DEMO-0661
Date: 2026-08-22
Collected by: Engineering Delivery

Site teams report that answers now arrive with the clause reference attached,
which they say removes a round trip they used to make to confirm where an
answer came from. Three site teams raised this unprompted.

No counts are available. The mailbox is not instrumented and we did not run a
before-and-after survey.

One genuinely new thing: queries can now be answered against the project's own
issued documentation rather than from memory. Before this, an engineer either
remembered the clause or went looking for it; there was no route that produced
the citation automatically.
