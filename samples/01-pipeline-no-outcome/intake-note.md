# Intake note — DEMO-0418

Raised by: Procurement Operations
Date: 2026-08-19

Onboarding packs arrive incomplete. Coordinators chase the missing items by
email, and a supplier cannot be activated until the pack is complete. Nobody
currently measures how long that chase takes or how often it happens — the
process sits outside the workflow tool, so there is no export to pull.

No baseline has been established. Procurement Operations has been asked to
start recording activation delays from Q4 so that a baseline exists before any
build begins.
